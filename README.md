# ของขวัญ — เว็บเล่าเรื่องของเราสองคน

เว็บไฟล์เดียว (`index.html`) เปิดบนมือถือ/คอมได้เลย เล่าเรื่องตั้งแต่วันแรกที่เจอกันจนถึง "แต่งงานกันนะ"
โทน: มินิมอล-อบอุ่น · ข้อความครบทุกคำจากต้นฉบับ · มี 3 จุด interactive

## วิธีดู
- ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย (มือถือแนะนำเปิดผ่านลิงก์หลัง deploy)

## 3 Interaction ที่แฟนได้เล่น
1. **เปิดเรื่อง** — ลากแสง 2 ดวงมาชนกัน
2. **ตั้งใจจุ่ม (จุดพีค)** — ลาก/แตะหมูคุโรบูตะใส่หม้อ → จอเขินชมพู + หัวใจลอย
3. **ตอนจบ** — เซ็นชื่อลงนาม "แต่งงานกันนะ" → กลีบดอกไม้ลอย

## รูปในเว็บ (แปลง+จัดวางให้แล้ว)
รูปจริงจากโฟลเดอร์ `รูปเพื่อทำเว็บผิง` ถูกแปลง HEIC→JPG (ย่อขอบยาว 1600px) จัดเข้า `images/` แล้ว:
- `images/table/` (2) — ฉากเจอกันที่โต๊ะ → **กองรูป**
- `images/trip/` (5) — ฉากเฌอเฌอ/ทริปต่างจังหวัด → **กองรูป**
- `images/propose/` (4) — ช็อตตอนขอเป็นแฟน → **กองรูป (เพลงอายเล่นตรงนี้)**
- `images/memories/` (12) — กอง "ความทรงจำของเรา" (ก่อนฉากขอบคุณ)

**กองรูป (polaroid pile):** ลากสับได้ · แตะ = ดึงขึ้นบน · **ดับเบิลคลิก = ขยาย** (lightbox เลื่อน ‹ › ดูทีละรูปได้)
อยากเพิ่ม/เปลี่ยนรูปในกองไหน: แก้ค่า `data-imgs="..."` ของ `<div class="pile">` ในฉากนั้น (คั่นด้วย ,)

## การ์ดร้าน + แผนที่ (โหลดแผนที่ Google อัตโนมัติ)
4 ฉากที่ไม่มีรูปใส่การ์ดร้าน + แผนที่ฝังจริงให้แล้ว: **le café phénix** (กาแฟ) · **Eat Am Are MBK** (กินข้าว) · **ตั้งใจจุ่ม · บรรทัดทอง** · **ร้านถ้วยถัง**
- อยากเปลี่ยนหมุดแผนที่: แก้ `data-q="..."` ของการ์ดร้านนั้น
- อยากใส่รูปร้านจริง (ไม่บังคับ): วางไฟล์ที่ `images/places/cafe.jpg`, `eatamare.jpg`, `banthadthong.jpg`, `thuaythang.jpg` — ถ้ามีจะขึ้นแทนกล่อง placeholder เอง
- ⚠️ แผนที่ + lightbox ต้องเปิดผ่านเน็ต/localhost (ดับเบิลคลิกไฟล์ตรง ๆ แผนที่จะไม่ขึ้น)

## เพลง "อาย" (เล่นจาก YouTube แล้ว — ไม่ต้องหาไฟล์เพลง)
ฝัง MV "อาย - สิงโต นำโชค" ไว้แล้ว (ซ่อนตัวเล่นไว้ เล่นแต่เสียง)
- เพลงเล่นอัตโนมัติเมื่อเลื่อนถึง **ช็อตตอนขอเป็นแฟน** (ถัดจากฉากเฌอเฌอ)
- ฉากเฌอเฌอมีปุ่ม **"🎵 แตะเพื่อฟังเพลงอาย"** ให้กดเองได้ด้วย (กันปัญหา iPhone บล็อกเสียงอัตโนมัติ)
- ปุ่ม 🔊 มุมขวาบน = เปิด/ปิดเพลง
- อยากเปลี่ยนเป็น MV เวอร์ชันอื่น: เปิด `index.html` หา `var YT_ID = "SjEQrlpshSw";` แล้วเปลี่ยนเป็นรหัสวิดีโอ YouTube ที่ต้องการ

## ✍️ ลงนาม 2 คน (เหมือนใบทะเบียนสมรส)
หน้าจบมี 2 ช่องเซ็น — "ว่าที่เจ้าบ่าว" กับ "ว่าที่เจ้าสาว" ต้องเซ็นครบทั้งคู่ปุ่มถึงจะกดได้
พอลงนามเสร็จ ดาวน์โหลดใบสัญญาที่มีลายเซ็นทั้งสองคน + วันที่ได้เลย

## 📤 เอาขึ้นเน็ตให้แฟนเปิดผ่านลิงก์ (ทำเองง่ายสุด — ไม่ต้องล็อกอิน)
1. **ใส่รูปให้ครบก่อน** (ดูหัวข้อ "ใส่รูปเอง" ด้านบน)
2. เปิดเว็บ **netlify.com/drop** (มือถือ/คอมก็ได้)
3. **ลากโฟลเดอร์ `gift-web` ทั้งอัน** ไปวางในหน้านั้น
4. รอสักครู่ → ได้ **ลิงก์** ทันที ส่งให้แฟนเปิดได้เลย (ลิงก์เดาไม่ถูก คนอื่นหาไม่เจอ)
5. อยากแก้/เพิ่มรูปทีหลัง → ลากโฟลเดอร์ไปวางใหม่ ได้ลิงก์อัปเดต

**ทางเลือกอื่น:** ถ้าอยากได้ลิงก์ถาวรสวย ๆ (เช่น GitHub Pages / Firebase) บอกก๊องได้ เดี๋ยวช่วยตั้งให้ (ต้องล็อกอินบัญชีก่อน)

## ✨ Tier 1 upgrades (เพิ่มแล้ว 11 ส.ค.)
- **🧵 เส้นด้ายแดงแห่งโชคชะตา** — เส้นบาง ๆ ร้อยทุกฉากตั้งแต่ต้นจนจบ วาดตามที่แฟนเลื่อน (ตำนานด้ายแดง = ตรงกับธีม "โลกอยากให้เราคบกัน")
- **ธรณีประตูเปิด** — หน้าแรก "ถึง [ชื่อเธอ]" + ปุ่มแตะเพื่อเริ่ม (ปลดล็อกเสียงเพลงในตัว)
- **loop เปิด-ปิด** — เปิดด้วยคำถาม "โลกจับเรามาเจอกันเพื่ออะไร?" → เฉลยตอนจบ "…ก็เพื่อสิ่งนี้"
- **ฉากเมาครั้งแรก = จอมืด** (valley) ทำให้พีคหลังจากนั้นสว่างเด่น
- **ใบสัญญาดาวน์โหลดได้** — หลังเซ็นเสร็จ กดเก็บเป็นรูป .png ไว้ได้
- **สั่นเบา ๆ (haptics)** ตอนแสงชน/หมูลงหม้อ/เซ็นเสร็จ บนมือถือ
- **ฟิลเตอร์รูปอุ่น** ให้รูปหลายที่ดูเป็นชุดเดียว

### ⚠️ 2 อย่างที่ต้องเติมเอง
1. **ชื่อเล่นแฟน** — เปิด `index.html` หา `var HER_NAME = "เธอ";` แล้วเปลี่ยนเป็นชื่อเล่นแฟน (บอกผมก็ได้ เดี๋ยวใส่ให้)
2. **องก์อนาคต** — ฉาก "หลังจากนี้เราอยากอยู่ด้วยกันแบบไหน" ยังเป็นข้อความ placeholder รอก๊องเขียนคำจริง (มองหา `id="futureText"` หรือส่งคำมาให้ผมวางแทน)
